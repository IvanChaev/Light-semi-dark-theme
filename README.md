# 🌙 Smart Dark Gray — умное затемнение сайтов

**Smart Dark Gray** — это интеллектуальное расширение для Google Chrome, которое автоматически затемняет светлые веб-страницы, защищая ваши глаза в темное время суток[cite: 2, 7]. Главная фишка: оно определяет реальную яркость сайта и инвертирует только светлые страницы, вообще не трогая сайты, у которых уже есть своя нативная темная тема[cite: 1, 2]!

## ✨ Что умеет расширение

* **Интеллектуальный анализ:** Скрипт мгновенно считывает реальный цвет фона страницы[cite: 1]. Если сайт светлый — включается мягкая темная тема[cite: 1]. Если сайт изначально темный — расширение просто проходит мимо[cite: 1, 2].
* **Умная защита медиа:** Расширение не ломает картинки (`<img>`), видео (`<video>`), векторную графику (`<svg>`) и холсты (`<canvas>`)[cite: 7]. Специальный алгоритм повторно инвертирует их, возвращая им оригинальные и естественные цвета[cite: 7].
* **Смягчение контраста:** Никакого ядовитого белого текста на абсолютно угольном фоне. Поверх страницы накладывается едва заметный серый тон, который убирает резкую контрастность и делает чтение максимально комфортным для глаз[cite: 7].
* **Быстрое управление (Popup):** Кликните по иконке на панели браузера, чтобы в один клик отключить затемнение для текущего сайта или включить его обратно[cite: 2, 6]. Страница обновится автоматически[cite: 6].
* **Продвинутый список исключений:** Управляйте всеми заблокированными сайтами на отдельной странице настроек[cite: 2, 3]. Достаточно внести основной домен (например, `example.com`), и все его поддомены (`m.example.com`) будут исключены автоматически[cite: 1, 3].
* **Облачная синхронизация:** Ваш список исключений автоматически синхронизируется между всеми вашими устройствами через Google-аккаунт благодаря `chrome.storage.sync`[cite: 1, 4].
* **Поддержка SPA и динамических сайтов:** Благодаря встроенному `MutationObserver`, расширение корректно обрабатывает страницы, которые догружают контент или меняют стили на лету без перезагрузки[cite: 1].

## 🚀 Как установить расширение в Google Chrome

Поскольку это расширение распространяется напрямую через код, а не через официальный магазин, вам потребуется использовать «Режим разработчика». Это стандартная функция Chrome, позволяющая запускать проекты, которые вы скачали самостоятельно.

### Шаг 1. Подготовьте файлы проекта
1. Cкачайте файлы расширения с GitHub или [отсюда](https://drive.google.com/uc?export=download&id=1f1d2c5wrJ_25_U1n2NM8bWbrZZHN08e_} и распакуйте их в любую удобную папку на компьютере.
2. Убедитесь, что в корне этой папки находятся файлы `manifest.json`, `content.js`, `styles.css` и остальные компоненты проекта[cite: 2].

### Шаг 2. Подготовьте браузер
1. Откройте Google Chrome (или любой другой браузер на базе Chromium).
2. Вставьте в адресную строку этот путь и нажмите Enter: `chrome://extensions/`
3. В правом верхнем углу найдите переключатель **«Режим разработчика»** (Developer mode) и активируйте его. 
   *Без этого переключателя браузер будет блокировать установку любых расширений, скачанных не из официального магазина.*

### Шаг 3. Установка
1. После включения «Режима разработчика» в левом верхнем углу страницы появится кнопка **«Загрузить распакованное расширение»** (Load unpacked).
2. Нажмите её и выберите папку проекта, в которой лежит файл `manifest.json`[cite: 2].
3. Готово! В списке расширений появится **Smart Dark Gray**[cite: 2].

**Важные советы:**
* **Не удаляйте папку:** Chrome запускает расширение прямо из этой папки. Если вы её переместите или удалите, расширение перестанет работать.
* **Предупреждения при запуске:** Поскольку расширение установлено локально, Chrome может иногда выводить уведомление о «режиме разработчика» при старте — это нормально, просто нажимайте «Отмена» или игнорируйте его.

**Поздравляем! 🎉**  
Расширение установлено и готово защищать ваше зрение! Нажмите на значок пазла 🧩 в панели инструментов Chrome (справа сверху) и закрепите **Smart Dark Gray** скрепкой, чтобы управление всегда было под рукой[cite: 2].

## ⚙️ Настройка под себя

Вы можете гибко управлять работой расширения:
* **Быстрый переключатель:** Кликните по иконке 🌙 на панели браузера, чтобы мгновенно добавить текущий сайт в исключения или убрать его оттуда[cite: 2, 6].
* **Полноценный список:** В Popup-меню нажмите ссылку «Список исключений», чтобы открыть страницу настроек[cite: 3, 5, 6]. Там можно вручную вносить домены (по одному на строку) и массово редактировать список[cite: 3].

## 🛠 Технологии

Проект написан на чистом JavaScript (Vanilla JS), HTML5 и CSS3 с использованием современного API `Manifest V3` для Google Chrome[cite: 2]. Расширение не использует тяжелых сторонних библиотек, не нагружает процессор и работает максимально легковесно[cite: 1].

Математическая модель вычисления яркости фона основана на стандарте относительной светимости[cite: 1]:
$$\text{Luminance} = 0.299 \times R + 0.587 \times G + 0.114 \times B$$[cite: 1]
