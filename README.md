# 🌙 Smart Dark Gray — умное затемнение сайтов

«Программное обеспечение предоставляется "как есть" (AS IS), без каких-либо гарантий».

**Smart Dark Gray** — это интеллектуальное расширение для Google Chrome, которое автоматически затемняет светлые веб-страницы, защищая ваши глаза в тёмное время суток. Главная фишка: определяет реальную яркость сайта и инвертирует только светлые страницы, не трогая тёмные темы.

---

## ✨ Что умеет расширение

* **Интеллектуальный анализ** – скрипт мгновенно считывает реальный цвет фона страницы. Если сайт светлый – включается мягкая тёмная тема. Если сайт изначально тёмный – расширение просто проходит мимо.
* **Умная защита медиа** – расширение не ломает картинки (`<img>`), видео (`<video>`), векторную графику (`<svg>`) и холсты (`<canvas>`). Специальный алгоритм повторно инвертирует их, возвращая оригинальные и естественные цвета.
* **Смягчение контраста** – никакого ядовитого белого текста на абсолютно угольном фоне. Поверх страницы накладывается едва заметный серый тон, убирающий резкую контрастность и делающий чтение максимально комфортным для глаз.
* **Гибкая настройка в попапе** – откройте всплывающее окно, кликнув по иконке расширения, и регулируйте:
  - **Интенсивность затемнения** – от лёгкого полутона до насыщенного тёмного режима.
  - **Порог срабатывания** – настройте, насколько ярким должен быть сайт, чтобы включилось затемнение (от «красит почти всё» до «только ярко-белые»).
  - **Персональные настройки для текущего сайта** – включите тумблер, и ваши значения сохранятся только для этого домена, переопределяя глобальные.
* **Быстрое управление исключениями** – кнопка «Отключить на этом сайте» / «Включить затемнение здесь» в попапе позволяет мгновенно добавить или убрать текущий сайт из списка исключений.
* **Продвинутый список исключений** – управляйте всеми заблокированными сайтами на отдельной странице настроек. Достаточно внести основной домен (например, `example.com`), и все его поддомены (`m.example.com`) будут исключены автоматически.
* **Облачная синхронизация** – ваш список исключений, глобальные и персональные настройки автоматически синхронизируются между всеми вашими устройствами через Google-аккаунт благодаря `chrome.storage.sync`.
* **Поддержка SPA и динамических сайтов** – благодаря встроенному `MutationObserver`, перехвату истории и `storage.onChanged`, расширение корректно обрабатывает страницы, которые догружают контент или меняют стили на лету без перезагрузки.
* **Автоотключение на тёмных сайтах** – расширение не применяет затемнение, если сайт явно сообщает о своей тёмной теме через `<meta name="color-scheme">`, CSS-класс `dark` или атрибут `data-theme="dark"`.

## 🆕 Что нового в версии 2.0.0

- **Настройки прямо в попапе** – больше не нужно лезть в отдельную страницу для изменения интенсивности и порога.
- **Персональные настройки для каждого сайта** – включайте тумблер и задавайте уникальные значения для текущего домена.
- **Улучшенное определение фона** – учитываются корневые элементы SPA (`#root`, `#app`, `#__next`) и делается выборка по координатам, что повышает точность на сложных сайтах.
- **Живое применение** – изменения настроек подхватываются на открытых вкладках без перезагрузки.
- **Оптимизация производительности** – MutationObserver отключается после бездействия, снижая нагрузку на процессор.
- **Поддержка SPA-навигации** – перехват `pushState`/`replaceState` и событие `popstate` обеспечивают корректную работу на одностраничных приложениях.

## 🚀 Как установить расширение в Google Chrome

Поскольку это расширение распространяется напрямую через код, а не через официальный магазин, вам потребуется использовать **«Режим разработчика»**. Это стандартная функция Chrome, позволяющая запускать проекты, которые вы скачали самостоятельно.

### Шаг 1. Подготовьте файлы проекта
1. Скачайте файлы расширения с GitHub или [отсюда]( )и распакуйте их в любую удобную папку на компьютере.
2. Убедитесь, что в корне этой папки находятся файлы `manifest.json`, `content.js`, `styles.css`, `popup.html`, `options.html` и остальные компоненты проекта.

### Шаг 2. Подготовьте браузер
1. Откройте Google Chrome (или любой другой браузер на базе Chromium).
2. Вставьте в адресную строку этот путь и нажмите Enter: `chrome://extensions/`
3. В правом верхнем углу найдите переключатель **«Режим разработчика»** (Developer mode) и активируйте его.  
   *Без этого переключателя браузер будет блокировать установку любых расширений, скачанных не из официального магазина.*

### Шаг 3. Установка
1. После включения «Режима разработчика» в левом верхнем углу страницы появится кнопка **«Загрузить распакованное расширение»** (Load unpacked).
2. Нажмите её и выберите папку проекта, в которой лежит файл `manifest.json`.
3. Готово! В списке расширений появится **Smart Dark Gray**.

**Важные советы:**
* **Не удаляйте папку** – Chrome запускает расширение прямо из этой папки. Если вы её переместите или удалите, расширение перестанет работать.
* **Предупреждения при запуске** – поскольку расширение установлено локально, Chrome может иногда выводить уведомление о «режиме разработчика» при старте – это нормально, просто нажимайте «Отмена» или игнорируйте его.

**Поздравляем! 🎉**  
Расширение установлено и готово защищать ваше зрение! Нажмите на значок пазла 🧩 в панели инструментов Chrome (справа сверху) и закрепите **Smart Dark Gray** скрепкой, чтобы управление всегда было под рукой.

## ⚙️ Настройка под себя

У расширения два уровня настроек:

### Глобальные (действуют для всех сайтов)
- **Порог срабатывания** (0–255) – яркость, выше которой сайт считается светлым и затемняется. По умолчанию `160`.
- **Интенсивность затемнения** (0–100) – степень затемнения: `0` – выключено, `100` – максимально тёмное. По умолчанию `50`.

Изменить их можно в попапе – просто двигайте ползунки, не включая «Свои настройки для этого сайта».

### Персональные (для конкретного домена)
- Включите тумблер **«Свои настройки для этого сайта»** в попапе, затем задайте свои значения порога и интенсивности. Они будут применяться только на текущем сайте и переопределят глобальные.

### Список исключений
- В попапе нажмите ссылку **«Список исключений сайтов →»** или откройте страницу настроек расширения. Там вы можете вручную добавить домены (по одному на строку). Поддомены исключаются автоматически.

### Быстрый переключатель
- Кнопка **«Отключить на этом сайте»** / **«Включить затемнение здесь»** позволяет мгновенно добавить или убрать текущий сайт из списка исключений без открытия страницы настроек.

Все изменения сохраняются в облаке и применяются на всех ваших устройствах.

## 🛠 Технологии

Проект написан на чистом JavaScript (Vanilla JS), HTML5 и CSS3 с использованием современного API `Manifest V3` для Google Chrome. Расширение не использует тяжёлых сторонних библиотек, не нагружает процессор и работает максимально легковесно.

Математическая модель вычисления яркости фона основана на стандарте относительной светимости:

$$ \text{Luminance} = 0.299 \times R + 0.587 \times G + 0.114 \times B $$

Для динамического управления стилями используются CSS-переменные (`--smart-dark-contrast`, `--smart-dark-brightness`, `--smart-dark-overlay`), которые задаются через JavaScript и позволяют плавно регулировать интенсивность.
